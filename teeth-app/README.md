# 🦷 치아 붙이기

사진에 치아를 자동으로 붙여주는 브라우저 기반 웹앱입니다.

## 사용법

1. `index.html`을 브라우저로 열기 (더블클릭 또는 드래그)
2. **📁 사진 선택** 버튼으로 사진을 올리거나, 화면에 끌어다 놓기 / Ctrl+V 붙여넣기
3. 얼굴 인식이 완료되면 입 위치에 맞춰 치아가 자동으로 붙습니다 (여러 명 인식 가능)
4. 슬라이더로 조절:
   - **너비** — 치아 좌우 크기
   - **길이** — 치아 세로 길이
   - **위/아래** — 치아 위치 조정
   - **하얗게** — 미백 강도
5. **💾 저장하기**로 PNG 저장

## 요구 사항

- 인터넷 연결 (얼굴 인식 모델인 MediaPipe Face Mesh를 CDN에서 1회 내려받음)
- 사진은 브라우저 안에서만 처리되며 어디로도 전송되지 않음
